# 06: Annual Substance Total (`연간 화학물질 총 수입량`) Aggregation, A4 PDF/Print Report & Mode-Aware `.xlsx` Export

**What to build:** Deliver Workspace 4 (`4. 연간 물질 집계 & A4 보고서`) end-to-end. Users filter by Target Year (`대상 연도`) or date range, `Domestic Importer` (`국내 수입사` or `전체 수입사`), optional `Overseas Branch` (`해외지사`), and optional `Imported Product` (`수입제품코드`) to compute exact fixed-point `Substance Import Weight` (`화학물질 환산 중량`) and `Annual Substance Total` (`연간 화학물질 총 수입량`) in `kg` and `ton` (`= kg / 1,000`) per unique `CAS번호`. Users can switch between **External Importer Summary Mode (`대외 제출용 요약본`, default)**—which strictly omits confidential `함유율(%)` and recipe breakdowns from the preview, A4 print/PDF output, and single-sheet `.xlsx` export—and **Internal Verification Detail Mode (`내부 검증용 상세본`)**, which displays the per-shipment recipe calculation breakdown in both the A4 report and a two-sheet `.xlsx` workbook.

**Blocked by:** 01: Walking Skeleton — Desktop Shell, SQLite WAL Schema, Fixed-Point Core & Sample Data Seed

**Status:** ready-for-agent

- [ ] Filtering by year/period, `국내 수입사`, `해외지사`, and `수입제품코드` executes the indexed SQLite join and aggregates `Substance Import Weight` ($\text{Import Weight kg} \times (\text{Weight Pct} / 100)$) and `Annual Substance Total` (`kg` and `ton = kg / 1,000`) per `CAS번호` in Rust using exact unrounded `rust_decimal::Decimal` arithmetic, rounding only at final display/export.
- [ ] **External Importer Summary Mode (`대외 제출용 요약본`, default)** renders the A4 report header (title, period, importer, branch, issue date, summary statistics) and summary table (`NO`, `CAS번호`, `화학물질명`, `연간 총 수입량 (kg)`, `연간 총 수입량 (ton)`), strictly excluding any per-product `함유율(%)` or recipe breakdown from the DOM print tree and PDF output.
- [ ] **Internal Verification Detail Mode (`내부 검증용 상세본`)** appends the contributing shipment breakdown (`수입일자`, `국내 수입사`, `해외지사`, `수입제품코드`, `제품 수입량 (kg)`, `함유율 (%)`, `화학물질 환산 중량 (kg / ton)`) under each `CAS번호` for internal verification.
- [ ] A4 Print / PDF output (`@media print` + `window.print()` / `PrintToPdf`) uses `@page { size: A4 portrait; margin: 14mm 12mm; }`, `'Malgun Gothic', '맑은 고딕', sans-serif`, `print-color-adjust: exact`, and clean multi-page table pagination (`thead { display: table-header-group; }`, `tr { break-inside: avoid; }`).
- [ ] `.xlsx` export via `rust_xlsxwriter` produces a 1-sheet workbook (`연간물질집계_요약`, zero confidential `함유율(%)` data) in External Summary Mode and a 2-sheet workbook (`1_연간물질집계_요약` + `2_수입실적별_상세내역`) in Internal Detail Mode, formatting `CAS번호` and `수입제품코드` with `@` text format (`set_num_format("@")`), applying numeric formats (`#,##0.00` / `#,##0.0000`) to weights, and auto-fitting column widths via `unicode-width` (2 units per Hangul syllable).
